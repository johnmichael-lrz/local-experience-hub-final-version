# LIFELINE Makati - Community Emergency Services Hub 

> A centralized, community-based emergency services directory designed to connect Makati City residents with rapid medical, fire, police, and disaster response resources.

## 📖 Project Overview
LIFELINE Makati was developed to address a critical gap in community preparedness: the lack of a centralized, accessible directory for emergency services. This web application bridges that gap by curating verified hotline numbers, mapping evacuation centers, profiling trusted volunteer responders, and providing essential first-aid knowledge.

## Key Features
* **Emergency Hotlines Directory:** A comprehensive, categorized table of verified emergency contacts (Medical, Fire, Police, DRRMO, etc.).
* **Interactive Fire Safety Guide:** An interactive HTML image map teaching the P.A.S.S. protocol for fire extinguisher use.
* **Evacuation Centers Map:** A tabbed interface displaying primary and secondary designated safe zones in Makati City.
* **Volunteer Network:** Profiles of dedicated community service providers.
* **Hazard Reporting:** A user inquiry and contact form to report local hazards to the DRRMO.

## Technologies Used
This project was built using standard web technologies with a focus on responsiveness and modern UI/UX design (glassmorphism).
* **HTML5:** Semantic page structure and interactive image mapping.
* **CSS3:** Custom styling, gradients, frosted-glass effects, and animations.
* **Bootstrap 5.3.0:** Responsive grid system, navigation bar, carousel, and accordion components.
* **Bootstrap Icons 1.11.3:** High-quality SVG UI icons.

## How to Run the Project
Since this is a static website, no local server installation is strictly required.
1. Clone this repository to your local machine:
   `git clone https://github.com/yourusername/lifeline-makati.git`
2. Open the project folder.
3. Double-click the `index.html` file to open it in your default web browser (Google Chrome recommended).
